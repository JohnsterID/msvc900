Microsoft Visual C++ 9.0 (MSVC v9.0 / 15.00.21022.08)

This is a stripped version that can reliably compile C++.

    Product version: 9.0
    Compiler (c1xx.exe) version: 15.00.21022.08

```
git clone https://github.com/archaic-msvc/msvc900.git
call msvc900\VC\Auxiliary\Build\vcvarsall.bat x86
call msvc900\VC\Auxiliary\Build\vcvarsall.bat x86_amd64
call msvc900\VC\Auxiliary\Build\vcvarsall.bat amd64
```

:: you can use cl, link, ...
